## 📌 About the Project

This is a simple C++ console application that simulates a basic login system with username and password validation.

---

## 🚀 Features

- 🔐 User authentication
- 🔑 Password validation
- 🖥️ Console interaction
- 🔁 Basic menu system

---

## 🛠️ Technologies

- C++
- Standard Library (`iostream`, `string`)

---

## 💻 How it works

1. User enters username
2. User enters password
3. System validates credentials
4. If correct, user gains access

---

## 🎯 Learning Goals

- Practice conditional statements
- Understand logical operators
- Simulate authentication systems
- Improve user interaction
